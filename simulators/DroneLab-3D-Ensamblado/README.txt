DRONELAB 3D V5.3 — MONTAJE DE DRON Y PILOTO

PARA ABRIR
1. Descomprime el ZIP completo.
2. Abre index.html en Chrome o Edge.
3. Puedes publicar la carpeta completa en Netlify.

CAMBIOS V5.3
- En el paso de cableado, haz clic en ORIGEN o DESTINO dorados sobre el modelo del dron: se conecta el cable actual y se avanza al siguiente. El botón Conectar sigue funcionando.
- Los puntos tienen un halo grande para facilitar los clics.
- Figura del piloto mejorada, radio RC reducida a tamaño portátil y sujeta con las manos.
- Dron completo y Piloto listo se calculan independientemente.
- El banco de cada vista solo muestra sus propios componentes.
- GPS: el modelo educativo no incluye GPS integrado. Un módulo GNSS externo es opcional para funciones de navegación compatibles; no es necesario para FPV manual. No forma parte del montaje obligatorio de esta versión.

AVISO
Es un simulador visual educativo. La configuración eléctrica se basa en un ejemplo y no reemplaza manuales técnicos, medidas con multímetro ni pruebas reales de seguridad. Las pruebas de motores físicos deben hacerse sin hélices instaladas.
